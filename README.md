# رَجْع | RAJA

**كل صوتٍ له رَجْع**

رابط الموقع: https://raja.athat.app

## وظائف الواجهة المنشورة

- مشغل فيديو وصوت وروابط YouTube القابلة للتضمين.
- تنزيل روابط الملفات المباشرة عندما يسمح الخادم بذلك.
- مكتبة خاصة بكل جهاز باستخدام IndexedDB؛ تظل الملفات على الجهاز ولا ترفع إلى خادم رَجْع.
- شاشة كشف صيغ MP4/MP3 وتصدير الملفات إلى تنزيلات الجهاز عندما يكون خادم المعالجة متاحًا.
- تطبيق ويب PWA يمكن تثبيته على الشاشة الرئيسية.

## تنزيل YouTube مباشرة داخل رَجْع

تم إعداد API في `functions/api` لتمرير الطلبات من `https://raja.athat.app/api/formats` و`/api/download` إلى خدمة معالجة خاصة باستخدام `yt-dlp[default]` و`FFmpeg` و`Node.js 22` الموجودة في مجلد `backend`. الخدمة **غير مفعّلة على الموقع تلقائيًا** لأن نشرها يحتاج استضافة خلفية مستقلة وإضافة عنوانها في إعدادات Cloudflare.

لإكمال الربط دون دفع رسوم:

1. أنشئ مشروعًا على خطة Render المجانية باستخدام ملف `render.yaml` الموجود في جذر المستودع.
2. انتظر نجاح نشر الخادم، وتحقق من `https://YOUR-SERVICE.onrender.com/health`.
3. في Cloudflare Pages، المشروع `raja`، أضف متغير بيئة Production:
   `MEDIA_BACKEND_URL=https://YOUR-SERVICE.onrender.com`
4. أعد نشر الفرع `main` على Cloudflare Pages.
5. اختبر تنزيل مقطع من رَجْع وتحقق من وصول ملف MP4 أو MP3 إلى الجهاز.

يرجى **عدم** وضع مفتاح أو رمز سري في المستودع. يمكن إدارة إعدادات Render وCloudflare من الحسابات المرتبطة.

**ملاحظة مهمة:** اختبار GitHub Actions نجح لبناء Docker وتشغيل `/health`، لكن تجربة استخراج الصيغ للرابط `https://youtu.be/-vVymc0wnLg` من خادم GitHub انتهت بخطأ HTTP 422؛ كان يوتيوب يطلب تحققًا إضافيًا. لا يوجد ضمان أن تنزيل أي رابط YouTube سينجح من خادم مجاني. قد يلزم تغيير جهة الاستضافة أو التحقق من صلاحيات الوصول، مع مراعاة حقوق النشر وشروط الخدمة. لا نحتفظ بنسخ دائمة من المقاطع على الخادم.

تفاصيل الخدمة واستخداماتها في [backend/README.md](backend/README.md).
